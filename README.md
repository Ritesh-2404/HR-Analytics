# 📊 HR Analytics Dashboard

An interactive HR Analytics Dashboard built using **Power BI, DAX, and Python** to analyze workforce demographics, employee satisfaction, engagement, compensation, and attrition trends.

---

## 🚀 Project Overview

This project transforms raw HR data into actionable business insights through interactive dashboards and KPI reporting. The dashboard helps HR teams understand workforce composition, employee experience, and key factors influencing attrition.

### 🎯 Business Objectives

* Monitor workforce demographics
* Analyze employee satisfaction and engagement
* Track compensation and training metrics
* Identify attrition trends and risk factors
* Support data-driven HR decision-making
